# ShopNex — Online Shopping Center

A responsive, full-stack e-commerce and store-management application built with **PHP, MySQL, Bootstrap 5, HTML5, CSS3, and JavaScript**.

ShopNex provides a complete online shopping experience with customer accounts, product management, inventory, order processing, staff permissions, and a customizable storefront.

## Features

### Customer Storefront
- Responsive homepage and product catalog.
- Browse products by category.
- Product search and filtering.
- Product details and image galleries.
- Customer registration and authentication.
- Profile and address management.
- Shopping cart and wishlist.
- Checkout and coupon application.
- Order history and invoice generation.
- Product reviews and ratings.
- Customer support tickets.

### Admin Dashboard
- Secure administrative authentication.
- Dashboard with store statistics.
- Product and category management.
- Multiple product image uploads.
- Inventory management.
- Order and customer management.
- Coupon management.
- Sales reports.
- Customer support management.
- Staff account management.
- Staff permissions and access control.
- Admin profile and password management.

### Staff Management
- Separate staff authentication.
- Permission-based dashboard.
- Restricted access to administrative features.
- Staff profile management.
- Server-side permission verification.
- Role-based access control.

### Manage Site — Store Customization
A WordPress-inspired customization system that allows administrators to manage the public storefront without directly editing source code.

Features include:
- Homepage content customization.
- Hero section image and text editing.
- Promotional banner management.
- Three predefined themes:
  - Modern Purple
  - Premium Blue
  - Vibrant Gradient
- Custom font selection for different website sections.
- Image positioning and adjustments.
- Live customization previews.
- Footer content management.
- Contact information management.

### Security Features
- Password hashing.
- Separate customer and operations sessions.
- Server-side role and permission checks.
- Active-account verification.
- CSRF protection on implemented forms.
- Secure, hashed, one-time password reset tokens.
- Account deletion/anonymization functionality.
